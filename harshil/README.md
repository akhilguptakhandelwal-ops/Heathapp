# Harshil — Voice Studio

Ek awaaz (Harshil), har emotion. Text likho → Harshil bolega: hasna, rona, gussa, fusfusana, dheema / tez.

## Versions
- **Version 1 · The Common Man** — roz ki kahaniyan, hasi aur aansu.
- **Version 2 · War History Explainer** — YouTube-style, battles aur wars ki gehri kahani.
- Naya version jodne ke liye `index.html` mein `VERSIONS` list mein ek entry daalein (naam, chips, example script, sample MP3).

## Chalana
1. App kholo → ⚙ Settings → apni ElevenLabs API key daalo (sirf phone mein save hoti hai).
2. Version chuno → script likho → emotion chips se `[laughs]`, `[sad]`, `[whispers]` jaise tag jodo.
3. **Harshil, bolo** → suno, Save MP3, Share.

Awaaz ElevenLabs ke `eleven_v4` model se banti hai (na chale to `eleven_v3`). Local test: `npx http-server harshil`.
